# PostCardly — Security Policy

## Data handling

PostCardly processes your photos and messages **entirely on-device**. We do not
upload, store, or access your content.

## No accounts or server

The App has no accounts, no backend, and no server-side storage. There is no
user data stored on our side to breach.

## Advertising

Ads are served by Google AdMob. Their data handling is governed by Google's
privacy policy.

## Network security

The App uses the platform's standard HTTPS/TLS for any network requests (ads and
app updates).

## Reporting a security issue

If you discover a security concern, please email
**shubhamg13.developer@gmail.com**.
